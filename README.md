# 貸しサロン 空き状況カレンダー

harmo-ver5 とは別に作った専用ページです。完成後にHPからリンクして使います。

## ファイル構成

```
salon-calendar/
├─ availability.html          ← ページ本体（HTML・CSS・JSが1ファイル）
├─ images/salon_calendar_bg.jpg   ← 背景画像
├─ gas/Code.gs                ← Googleカレンダーを読むスクリプト（本番用）
├─ gas/appsscript.json        ← GASの設定（タイムゾーン・公開設定）
└─ README.md
```

## いまの状態（重要）

- **サンプル表示**で動いています。空き状況はテスト用の自動生成データで、**実際の予約状況ではありません**。ページ上部と凡例の下に、その旨を常時表示します。
- **予約を保存する仕組みはありません。** このページは「空きの表示」と「メールでの問い合わせ導線」だけです。予約の確定は、メールのやり取りと、管理者のカレンダー入力で行います。
- `<meta name="robots" content="noindex">` を入れてあります（検索に出さない設定）。本番公開時に削除してください。

## 公開（GitHub Pages）

1. 新しいリポジトリ（例: `salon-calendar`）を作り、このフォルダの中身を置く
2. Settings → Pages → Branch を `main` / `(root)` にして保存
3. `https://（ユーザー名）.github.io/salon-calendar/availability.html` で開く
4. HP側から、このURLへリンクを貼る

## 本番化の手順（Googleカレンダー連携）

1. Googleカレンダーを2本作る：「貸しサロン 小部屋」「貸しサロン 大部屋」（**公開設定は不要・非公開のまま**）
2. 各カレンダーの設定 → 「カレンダーの統合」→ **カレンダーID** をコピー
3. [script.google.com](https://script.google.com) で新規プロジェクトを作り、`gas/Code.gs` を貼る
   （プロジェクトの設定で「appsscript.json をエディタで表示」を有効にし、`gas/appsscript.json` の内容も貼る）
4. `SETTINGS.CALENDARS` に2つのカレンダーIDを入れる
5. `testRun` を実行 → 権限を許可 → ログにJSONが出ればOK
6. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」→ 実行ユーザー「自分」／アクセス「全員」→ 発行されたURLをコピー
7. `availability.html` の `CONFIG.gasUrl` にそのURLを貼る → サンプル表示が消え、実データになります
8. 営業時間を実際に合わせる：`CONFIG.businessHours`（いまは仮の 9:00〜21:00）

## 運用ルール

- 利用が決まった時間を、該当カレンダーに**予定として入れる**だけで反映されます（反映まで最大5分）
- **貸し切りは、小部屋と大部屋の両方のカレンダーに入れる**
- 月額入居は、繰り返し予定で入れる
- 予定のタイトルは自由です（サイトには出ません）。ただし、他の人とカレンダーを共有する場合は、共有範囲に注意してください
- 公開範囲は `MONTHS_PUBLISHED`（GAS）で変更。それより先の日付は「－（情報準備中）」になります
- 読み込みに失敗した場合は、サンプルには**戻らず**、エラーを表示して全日「－」にします（偽の空き状況を出さないため）

## 将来、別の予約サイトを作ったら

`CONFIG.reservationUrl` にURLを入れると、「この日程で空きを問い合わせる」ボタンの行き先がメールからそのURLに変わります
（`?room=small&date=2026-10-12&time=10:00-12:00` の形で、部屋・日付・時間を渡します）。

## 動作確認済みの内容

- 月の切り替え：2026年10月〜2027年4月、うるう年（2028年2月）、年またぎ（12月→1月）、月末23:59 JSTで、曜日と日数が正しい
- 日曜始まり、前月は当月より前に戻れない、翌月は6か月先まで
- 3タブ（小部屋／大部屋／貸し切り）の切り替えと、貸し切り＝両部屋が空いている時間のみ
- 日付タップの詳細、時間の選択、メール文面の生成
- スマホ幅375px・390pxで横スクロールなし、日付マスは44px以上、文字は11px以上
- GAS連携のデータ経路（モック）：満室・一部空き・空き・公開期間外・取得失敗
